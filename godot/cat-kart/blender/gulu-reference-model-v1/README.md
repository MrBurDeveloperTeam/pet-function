# Gulu 立体建模 v1

根据四张参考图制作：原始六猫概念图（仅 Gulu）、六视图、五官结构图、底面补充。真实 Blender 网格，未将正面照片贴到脸上。

## 文件

- `gulu-sculpt.blend`：编辑主文件。连接的头部、耳朵、躯干和四肢；独立球形眼球、圆角鼻子、凹入鼻孔和口缝；条纹顶点色和短毛。四张参考图片已打包到隐藏的参考集合中，灯光和正交相机保留。
- `gulu-game.glb`：独立精简导出，米制、地面位于 Z=0（Blender），导出至 glTF 为 Y 向上、脸朝 -Z，包含真实网格和眼睛材质。
- `gulu-game.blend`：精简版源文件，方便后续绑定。
- `gulu-front/left/right/back/top/bottom.png`：同一个真实模型的正交渲染，底面保持同一坐姿。
- `gulu-face.png`：真实模型的五官特写。
- `validation.json`：连接性、三角面和文件大小检查。

## 后续集成

本次没有覆盖现有赛车角色，也没有更改六猫切换。模型是参考图风格的立体实现，并非逐像素完全匹配；五官、条纹和毛发仍可继续雕刻调整。

当前为静态坐姿，没有骨架、权重、握方向盘动作或表情动画。后续需要为头、躯干、前爪和尾巴绑定，并把坐姿调整到赛车座椅；不能把静态导出等同于完成驾驶动画。

毛色采用 `Coat` 顶点色，眼睛虹膜在球形表面通过贴图表达。Godot 导入应启用材质 `vertex_color_use_as_albedo`；当前赛车的模型加载器已支持。像素风应在游戏渲染端控制，不靠把参考图挤出成薄板。

展示版短毛比游戏版密集；游戏版保留较少毛束。实际帧率仍需放入目标赛车场景测量。
