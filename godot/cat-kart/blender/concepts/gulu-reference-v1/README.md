## 身份与建模原则

灰棕色虎斑、绿色虹膜、大黑瞳孔、粉色鼻子和内耳、奶油色口鼻胸毛和脚趾，不加项圈或围巾。头颅应有充分前后深度，耳根融合进头部，四肢连接躯干。眼球使用球体，浅眼眶和上下眼睑包裹眼球；虹膜与瞳孔通过曲面材质表达。鼻子是圆角三角形小体积，有轻微鼻翼和鼻孔凹陷。两侧胡须垫浅浅隆起，鼻下短纵沟连接闭合的 Y 形嘴缝，嘴缝是浅凹槽，不是浮在脸外的线条。

## 使用限制

这些是 AI 概念参考，不是由同一三维网格渲染的严格正交工程图。正面为身份基准；隐藏条纹、背面和肉垫是推定设计。左右视图可能有花纹、尾巴及比例偏差，按同一模型统一它们，不能把六个轮廓独立挤出后拼接。

底面生成多次仍带有展示腹部的姿态倾向，不能作为严格坐姿底视图直接描摹；补图仅参考肉垫及腹毛设计。准确底面应在 Blender 中建立统一坐姿网格后，从正交相机沿垂直向上方向渲染验证。

五官图中 MUZZLE + MOUTH 的部分 philtrum 标线误指鼻孔；正确位置是鼻子中央下方到嘴缝之间的短纵沟。眼部剖面是设计示意而非解剖测量图。

Blender 对照时先统一正面、侧面、背面比例，建立头、躯干及连接四肢，再刻画眼眶与鼻口；最后加毛色、条纹和短毛。赛车上车姿势与操控动画另做，不在这些参考图中。
