# Gulu 隐藏结构参考

根据用户六视图，通过内置 image_gen 生成两张用于 Blender 雕刻的结构概念图。

- `gulu-translucent-six-views.png`：六方向毛发外轮廓与内部体块、关节中心关系。
- `gulu-hidden-connections.png`：头颅眼眶、耳根、口鼻下巴、肩前腿、坐姿后腿、背部尾根的局部剖面。
- `PROMPTS.md`：完整生成提示词。

这些是推定结构示意，不是照片实际揭示的全部内部结构，也不是同一 3D 模型的严格投影或准确解剖图。各角度和局部体块需要在统一网格里验证，不能按不同面板各自挤出拼接。外观以用户原始 Gulu 正面、侧面轮廓为准，颜色体块仅用于解释连接关系，不是最后的毛色。

六视图中的底面仍偏展示腹部姿态，不能作为统一坐姿的准确底投影。局部图中部分英文标线有误：cranium 应指头颅而非耳尖；nostril 是鼻孔而不是嘴缝。后爪图多出的 'Hock pad' 不应直接照搬到 Gulu 后爪；此处仅采用四趾垫和掌/跖垫外观设计。前腿和后腿的关节中心线不是经过解剖测量的骨架。

建模优先统一圆润幼猫体型、四肢连接和耳根融合，随后确认球形眼球位于眼眶内、眼睑贴合眼球、口鼻体积自然过渡，再制作虎斑与毛发。动画骨架根据实际网格与坐姿单独设计。
