# 天赋云存档接入

本次新增 `air_strike_talent_cloud.sql`，与旧的进度/关卡字段 SQL 分开。它是独立迁移，不要求先运行 `air_strike_progress.sql` 或完整安装文件。你自行审核后决定是否执行，Codex 未连接 Supabase 或执行 SQL。

前提：猫咪钱包已经使用 `public.inventory_pet(user_id,coins)` 与 `public.mutate_pet_coins(integer)`。这是现有 App Gallery 仓库映射；执行前请核对你的数据库是否一致。新函数不修改猫咪等级或经验。

新表 `air_strike_talent_ownership` 是天赋唯一云端来源，旧 `air_strike_progress.unlocked_talents` 准备字段不参与此实现。读取和购买 RPC 从 `auth.uid()` 得到用户，客户端不能指定其他用户或任意价格。RLS 只允许读取自己的记录，不允许客户端直接写入天赋。

购买在同一事务里锁定天赋记录、验证 1→15 前置、按服务端价格调用现有金币扣款函数、记录天赋。扣款或存档失败时全部回滚。重复购买已拥有天赋返回现有记录和金币余额，不再次扣款。网络响应丢失后，界面暂停购买，先重新读取云端；不会退回本机再次扣款。

## 如何生效

1. 审核并手动运行 `air_strike_talent_cloud.sql`。
2. 使用真实已登录的猫咪页面，且通过 `createAppGalleryPetRepository` 的现有 Supabase 客户端打开。
3. 打开天赋榜，应显示“已同步云端”。同一账号换设备后自动读取。打开机库、打开天赋榜、窗口重新获得焦点或点击“重新读取云端”都会刷新记录。

`?pet-design=1` 的 LocalPetDesign 预览仍使用本地模拟钱包/仓库，不会连接数据库；界面显示“本机模式”。未提供云端仓库的其他宿主也仍使用原本本机模式。此文件仅启用永久天赋云同步；关卡与无限排行榜的独立云接入参见 AIR-STRIKE-CAMPAIGN-CLOUD.md。飞机云改装与完整部署参阅 AIR-STRIKE-COMPLETE-INSTALL.md；飞行 XP 仍为本机存档。

## 旧天赋迁移

旧版本的 localStorage 天赋不能证明云端已付款，不能直接上传并免费解锁，也不能自动重新扣款。首次读取后，旧记录保留到 `sky-patrol:talents:v1:用户UUID:legacy`。若这些项目不在云端，天赋榜显示缺少的编号并暂停购买，避免重复付款。云端记录作为当前所有权来源。

你核对旧购买后，可使用 SQL 文件末尾**已注释的管理员迁移示例**：自己填真实 auth UUID 与已确认的天赋编号，再选择执行。该示例合并记录、不再次扣币，也不删除云端已有项目。执行后点击“重新读取云端”。不要将未确认的本机记录直接当成购买证明。

无需为了此功能重复运行旧的完整安装 SQL。天赋云迁移没有合并到旧完整安装文件，便于单独审核。

## 验证范围

本地 mock 测试验证 RPC 路由、返回值、断网不二次扣款、旧记录与云记录的分离；前端与类型构建通过。SQL 事务逻辑已经静态检查，但没有在你的 Supabase 上执行或进行真实金币交易，需你部署后验证同账号跨设备读取和重复购买不扣款。
