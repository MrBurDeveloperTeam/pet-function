# Sky Patrol 永久天赋与局内技能

完整规则、奖励公式与 SQL 执行说明见 [AIR-STRIKE-CAMPAIGN.md](AIR-STRIKE-CAMPAIGN.md)。此版本替换早期的两条终极路线 Boss 门槛、开局额外选择、按敌方血量比例吸血与轰炸扣 Boss 25% 最大血量规则。

- 15 个永久天赋按 1→15 顺序购买，总价 26,000 猫咪金币；现有钱包 spendCoins 确认成功后授予。
- 第 3 项将候选由三选一变为四选一，每次仍只获得一个技能。
- 9 初始、9 进阶、6 终极技能检查前置条件，按关卡 Tier 权重和 50% / 25% 候选入池规则抽取。
- 普通关最多四条路线；无限模式解除限制。环形激光禁用反射效果，获得后不再出现反射 II。
- 开局、普通波次结束、能量球升级均提供技能选择；本局技能下次出击清空。
- Boss 按固定波数出现，不检查终极技能数量。
- 吸血按实际伤害回血，护盾挡下或超过目标剩余血量的伤害不会额外回血。
- 无人机以当前非暴击火力为基准；终极轰炸对 Boss 造成当前火力×5。
- 保命优先级：生命进化/高维生命体 → 不屈 → 复活；一次致命伤害只消耗一次能力。

天赋与关卡记录目前按用户保存在浏览器本机。SQL 仅准备可选云存档字段，未启用同步。没有连接 Supabase，未执行任何迁移。奖励沿用现有猫咪金币接口，未进行真实金币交易测试。
