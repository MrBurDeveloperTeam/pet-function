# 飞行等级与飞机改装

飞行等级与飞机款式分别保存。每局仍获得 floor(分数 / 100) 飞行经验，胜利额外获得 100 飞行经验；经验不会升级飞机，也不会改变猫咪等级。

维修台使用猫咪页面已有的金币，通过现有 spendCoins 确认扣款后才授予新飞机。没有飞机游戏独立金币。改装价格依次为 100、200、350、550、800、1100、1500、2000、2600 金币。金币不足或扣款失败不升级，同一时间只允许一次购买。

飞机款式已接入云端读取和原子购买接口；飞行经验、最高分与对局次数也已接入现有进度云端接口。金币沿用原有猫咪钱包。旧本机购买会保留备份，若高于云端等级则暂停购买，等待人工核对迁移。

完整安装请审核 air_strike_complete_install.sql，并参阅 AIR-STRIKE-COMPLETE-INSTALL.md。兼容已执行的旧飞机字段迁移；无需重复执行旧文件。Codex 未执行数据库 SQL。
